EVALUACIÓN 4 - CSS Y DISEÑO WEB RESPONSIVE
==========================================

Contenido: cuatro proyectos en HTML y CSS.

PROYECTO 1 - viewport-unidades
Abre proyecto1/index.html. Practica viewport, vw y vh.

PROYECTO 2 - imagenes-porcentuales
Abre proyecto2/index.html. Las imágenes de ejemplo se adaptan al ancho de su contenedor:
70%, 50% y 20%. Puedes reemplazar las imágenes de muestra por las del ejercicio.

PROYECTO 3 - media-queries
Abre proyecto3/index.html. El resumen se oculta por debajo de 600px; desde 600px
se muestra y el texto es rojo a 16px; desde 901px el texto pasa a negro a 14px.

PROYECTO 4 - mostly-fluid
Abre proyecto4/index.html. Las cajas se apilan en móvil, se distribuyen en tablet
y se reorganizan en escritorio.

CÓMO PROBAR
1. Descomprime la carpeta.
2. Abre cada index.html en Chrome o Edge.
3. Para probar distintos tamaños, presiona F12 y activa la barra de dispositivos
   (icono de móvil/tableta), o redimensiona la ventana.

GITHUB
Crea un repositorio en GitHub, sube la carpeta del proyecto y copia la URL del
repositorio dentro de github_url.txt. No entregues una URL inventada: debe ser
la dirección real de tu repositorio.

NOTA
Las imágenes son ilustrativas y locales. Si la plataforma exige reproducir
exactamente las imágenes de referencia del curso, reemplaza las imágenes de muestra
por las proporcionadas por el instructor.
